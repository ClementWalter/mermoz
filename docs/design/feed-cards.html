Keys in the feed

Ten card types, two variants each

Every card shares one anatomy: a kind label and the person, a title phrased as the thing to do, one line on why it matters now, the type's own body, then actions with their keys. The variants differ only in the body.

How the feed is built

StepWhoWhen
Open items: Unread, To do, In progress, Waiting; Backlog only if a date or a reply brings it backCodeAlways, instant
Per item: needs a reply, urgency, deadline, card type, automated, amountJevOn arrival, ~250 ms, cached
Order and section: deadline, then urgency × sender weight, then ageCodeEvery refresh, < 5 ms
Batch: automated + same kind → one clean-up cardCodeEvery refresh
Title, "why now", draft reply, digest summary, key pointsAILazily, when the card scrolls into view

The AI chooses the words; code chooses the order, so the order is stable and explainable.
