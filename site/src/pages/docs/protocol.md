# Mermoz JSON-RPC protocol (mermozd)

This is the protocol between Mermoz's daemon, `mermozd`, and its clients: the Mac app, the `mermoz` CLI and the MCP server. Use it to build your own client; for agents, the [CLI](/docs/cli/) and the [MCP server](/docs/mcp/) are simpler. Source: [docs/protocol.md]({{repo_url}}/blob/main/docs/protocol.md).
